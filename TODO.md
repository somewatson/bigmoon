# 📝 Big Moon Development Roadmap

## 🛠️ High Priority

### 1. Fix Library Dates & File Tracking
**Goal**: Resolve "Unknown Date" issues in "My Library" by ensuring files are correctly linked to database records.
- [ ] **Update `downloader.py`**:
    - Capture the actual final filename generated by `yt-dlp` after download completion.
    - Update the corresponding `DownloadTask` record in the database with this final filename.
- [ ] **Improve `app/main.py` (`list_library`)**:
    - Implement a fallback to `os.path.getmtime` if no `DownloadTask` record is found.
    - Ensure `created_at` is returned for both original and compressed files.
- [ ] **Verification**: Confirm that all files in the library show a date and are correctly categorized.

### 2. Twitch Chat Integration
**Goal**: Allow users to download and view Twitch chat synced with VODs.
- [ ] **Backend Setup**:
    - Add `chat-downloader` to `requirements.txt`.
    - Create `ChatMessage` model in `models.py` (columns: `id`, `task_id`, `username`, `message`, `time_in_seconds`, `timestamp`).
- [ ] **Download Pipeline**:
    - Implement `start_chat_download_async` in `downloader.py`.
    - Integrate chat download into the main VOD processing pipeline.
- [ ] **API Implementation**:
    - Create `/api/chat/<video_id>` endpoint to serve chat messages.
    - Create `/api/chat/export/<video_id>` endpoint to generate and serve a JSON export of the chat.
- [ ] **Frontend Integration**:
    - Add chat overlay/sidebar to the video player.
    - Implement "Download Chat JSON" button.
- [ ] **Verification**: Verify chat syncs with video playback and JSON export contains all messages.

## 📉 Medium Priority
- [ ] General performance optimization for thumbnail generation.
- [ ] Enhanced error reporting in the Admin Dashboard.
